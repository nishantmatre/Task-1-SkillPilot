SKILL PILOTS - SIMPLE COUNTER WEB APP

Project description:
A simple counter web app. The displayed number starts at 0. Clicking
"Increment +" increases the number by one. Clicking "Reset" returns it to 0.

Files:
- index.html  : page structure and buttons
- style.css   : page styling and responsive layout
- script.js   : counter variable and click event listeners

How to run:
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.
   OR open the folder in VS Code and use the Live Server extension.
4. Click "Increment +" to increase the number and "Reset" to return to zero.

Implementation steps covered:
1. Create HTML with a number display and Increment button.
2. Initialize a JavaScript counter variable to 0.
3. Attach a click event listener that increments the counter and updates the display.
4. Style the page with CSS.
